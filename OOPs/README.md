# Python OOP Basics

A small beginner-friendly set of Python files to learn classes and the four pillars of OOP.

## Files

1. `01_classes.py` — what a class and object are
2. `02_constructors.py` — how `__init__()` sets starting values
3. `03_encapsulation.py` — keeping data and related methods together
4. `04_inheritance.py` — reusing features from another class
5. `05_polymorphism.py` — the same method name behaving differently
6. `06_abstraction.py` — using a simple interface while hiding details
